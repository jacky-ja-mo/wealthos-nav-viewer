# WealthOS 净值观察网页

这是查询北银理财公开产品信息与历史净值的网页。已配置的产品由云端查询官网；网页对比经过校验的公开数据接口与 GitHub Pages 备用快照，展示最近一次成功采集的结果。两种公开来源都只含产品代码、官方名称、净值和采集状态；不包含私人持仓、成本或数据库密钥。

首次使用默认查询 `YJ01251204A`，之后记住上一次查询的代码。填写当前持有份额后，“最近一期估算收益”按最近两次已采集的单位净值差乘以当前份额，标注这两次的日期。它假设区间内份额不变，不包含申赎、分红和费用，并非当日真实到账收益；缺少上一条净值或持有份额时不会生成数字。

“刷新净值”只读取已采集的数据，不直接触发后台查询。官网未披露新值或后台查询失败时，保留上次真实记录并显示状态。原 GitHub Actions 计划为北京时间 09:20、18:20、22:20；Supabase 数据库备用定时检查在 09:35、18:35、22:35。平台调度和官网可用性无法保证，免费服务也有额度或暂停限制。公开网页的 GitHub 自动调度曾未按时触发，备用数据库定时在一次独立测试中真实执行成功；长期运行仍需观察。

## 持仓隐私

填写份额和成本后可选择“加密保存持仓”。密码派生密钥使用 PBKDF2-SHA-256，持仓使用 AES-256-GCM 加密，密文仅保存在当前浏览器。密码、份额、成本和估算收益不会上传，也不会自动跨设备同步。换设备前导出加密备份，在另一设备输入相同密码导入；清理浏览器数据可能删除本地资料。遗失密码后无法解密或找回，密码请勿使用银行密码。

这是个人本机加密功能，并非云端个人账户或银行级保障；共享设备、恶意扩展、设备遭入侵、网站代码遭篡改等风险仍需注意。网页不读取或迁移原私人云数据库的持仓。

本地测试：`node --test test-holding.cjs test-vault.cjs test-vault-ui.cjs`。测试持仓输入均为虚构样本，不发布为个人持仓。
